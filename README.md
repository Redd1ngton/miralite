# Замірник Lite

Самостійний статичний застосунок українською. Ворота, огородження та двері: швидкі заміри, фото, схема огорожі, ZIP для передачі, заповнення основних полів оригінальних PDF-бланків WIŚNIOWSKI.

## Cloudflare

Застосунок розміщено в окремому репозиторії `Redd1ngton/miralite`, гілка `main`.

Для окремого проєкту Cloudflare Pages: репозиторій `miralite`, production branch `main`, framework `None`, команда збірки порожня, вихідна директорія `.`. Усі файли застосунку лежать у корені. Підключення до Cloudflare налаштовується окремо.

Для локального запуску: `python -m http.server 8080` у папці застосунку, потім http://localhost:8080. Для PDF потрібен HTTP(S), не file://.

## Використання

1. Назвіть об’єкт; контакти введіть за потреби один раз.
2. Оберіть категорію, заповніть розміри у мм. Однакові секції можна дублювати.
3. Кнопка «Деталі» відкриває додаткові поля поточної категорії: конструкція, тиснення, направляючі, керування, монтаж та реквізити. Вибори не заповнюються автоматично.
4. Додайте фото камерою або з галереї. До 40 фото; кожне стискається до 1600 px, JPEG.
5. Для огородження натискайте на кути схеми, позначайте ворота/хвіртку. Це умовна схема без масштабу; розміри задаються окремими полями.
6. Натисніть «Підготувати результат». З’являться кнопки поширення ZIP, завантаження ZIP і PDF.

ZIP: `бланк_замірів.html` з вбудованими фото, `заповнені_бланки.pdf`, `дані.json`, окремі JPEG у папці фото. Системне поширення використовує Web Share на підтримуваних пристроях; інакше завантажується ZIP для ручного прикріплення.

## Збереження і приватність

Чернетка — у localStorage `zamirnyk-simple-v1`, фото — в окремому IndexedDB `zamirnyk-lite-photos-v1`. Дані не передаються на сервер, між пристроями не синхронізуються. Очищення даних браузера видаляє чернетку й фото. Якщо сховище недоступне, застосунок показує попередження. Перед закриттям у такому режимі обов’язково завантажте ZIP. Кнопка «Новий об’єкт» очищує дані після підтвердження. Імпорту JSON немає.

## PDF: поточний обсяг

Використовуються оригінальні надані бланки. Переносяться контактні дані, базові розміри, колір і підтримувані вибори. Для огородження — схема, розміри воріт/хвіртки та перші шість секцій. Усі дані, включно з наступними секціями та довгими примітками, повторюються в додатку. Фотографії додаються окремими сторінками.

«Деталі» містять технічні опції всіх чотирьох бланків, реквізити, контакти на об’єкті, ресурси замовника та підготовчі роботи. Вибрані опції відмічаються у шаблонах; усі введені значення також зберігаються в додатку PDF, HTML та JSON. Довгі значення в коротких клітинках зменшуються, а повний текст залишається в додатку. Тип Air grille та довільні позначення перших чотирьох відрізків (у шаблоні вони А–Д) наведено в додатку. Підписи не генеруються: поля представника, логіста та КВР призначені для імен. Галочка автоматики хвіртки не прирівнюється до електрозамка; електрозамок задається окремо.

Гаражні/промислові ворота та двері — по одному виробу на об’єкт; секцій може бути декілька. Поле «Двері» має один рядок. Редактор огорожі — послідовна ламана з позначками, без автоматичного зв’язування відрізків із секціями.

## Перевірки

Перевірено синтаксис JS, фільтрацію чисел, формування PDF на прикладі, візуальне розміщення полів у тестовому PDF, ZIP з українськими назвами. Браузерна перевірка камери, IndexedDB та системного поширення на iPhone в цьому середовищі недоступна.

## Залежності

Локальні pdf-lib і JSZip; ліцензії у vendor/. Зовнішніх CDN немає. Запуск і PDF не потребують серверного API. Права на вихідні бланки та брендинг належать їхнім правовласникам.
